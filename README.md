# JavaWeb AI Test - 前端项目

这是一个基于 **Vite** 构建的现代化 JavaWeb 前后端分离测试项目的前端部分。该项目主要用于验证前后端接口联调、AI 交互界面的数据展示以及整体业务流程的打通。

## 🛠️ 技术栈

*   **构建工具**：Vite (极速的前端构建工具)
*   **核心语言**：JavaScript / HTML5 / CSS3
*   **依赖管理**：npm / yarn
*   **开发编辑器**：VS Code (项目已包含 `.vscode` 配置)

## 📂 项目结构

```text
java-web-ai-test/
├── .vscode/            # VS Code 编辑器专属配置目录
├── src/                # 核心源代码目录（包含组件、样式、逻辑等）
├── index.html          # 项目入口 HTML 文件
├── package.json        # 项目依赖清单与运行脚本
├── package-lock.json   # 依赖版本锁定文件
├── vite.config.js      # Vite 打包与开发服务器配置文件
└── README.md           # 项目说明文档
